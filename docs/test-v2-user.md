### 0.3 ข้อมูลหลักของ SOMJAI (สร้างผ่านจอใน U3)

- **ช่องทางชำระ**
  - `CASH` เงินสด: มาจากการสมัคร, ปัด 0.25
  - `CARD` บัตรเครดิต: card, ต้องมีเลขอ้างอิง "เลขอนุมัติ", ค่าธรรมเนียม 2%
  - `QR` QR พร้อมเพย์: qr, PromptPay `0812345678`
  - `INST` ผ่อน 0%: installment, 3 / 6 / 10 เดือน, ขั้นต่ำ ฿3,000, ค่าธรรมเนียม 3%
  - `TRF` โอนเงิน: transfer, บัญชี "กสิกร 123-4-56789-0"
- **เครื่อง POS**
  - `1` แคชเชียร์หน้าร้าน: POS ID `E011234567001`
  - `2` เคาน์เตอร์หลังร้าน: ไม่มี POS ID
- **หมวดหมู่** (รหัส · ชื่อ):
  - แผนก `MOB` มือถือ
    - หมวด `MOB-PHN` สมาร์ทโฟน > หมวดย่อย `MOB-PHN-AND` Android
    - หมวด `MOB-ACC` อุปกรณ์เสริม > หมวดย่อย `MOB-ACC-CASE` เคส, `MOB-ACC-CBL` สายชาร์จ
  - แผนก `SRV` บริการ > หมวด `SRV-INS` ติดตั้ง
  - แผนก `PRE` เติมเงิน > หมวด `PRE-SIM` ซิม
- **ผู้จำหน่าย**
  - `SUP-SS` บริษัท ไทยซัมซุง อิเลคโทรนิคส์ จำกัด: `0105550333448`, สนญ., เครดิต 30 วัน
  - `SUP-ACC` ร้านส่งอุปกรณ์มือถือ: `0105550555661`, สาขา 00001, เงินสด

### U15 — ระบบ / ความปลอดภัย (D1 + D2)

#### U15.1 cookie / localStorage · จอ

- **จอ**:
  - cookie `an22.sid`: HttpOnly + SameSite=Lax (ไม่มี Secure เพราะ http local)
  - body ของ login ไม่มี `token`
  - localStorage ตาม U1.9
  - logout แล้ว `/api/me` → 401

#### U15.2 XSRF · API

- **ทำ**: จาก page ที่ login แล้วยิง `fetch('/api/settings/branch', {method:'PUT', …})` 2 แบบ:
  - ไม่มี header `X-XSRF-TOKEN`
  - header ปลอม
- **ผลที่คาด**: `403` "คำขอไม่ถูกต้อง กรุณาโหลดหน้าใหม่" ทั้งสองแบบ และ request ของแอปเองผ่าน
- **DB**: ไม่มีการเปลี่ยนในสาขา (`updated_at` เท่าเดิม)

#### U15.3 CSP / console · จอ

- **จอ**:
  - header `content-security-policy` มี `default-src 'self'`
  - ไล่เปิดทุกหน้าใน U16.2 แล้ว console ไม่มี CSP violation / error ที่ไม่ได้รับไว้
  - request นอก origin มีแค่ Google Fonts

#### U15.4 session ใน MongoDB · DB

- **ทำ**: login 3 บัญชีในเบราว์เซอร์ / curl คนละ cookie แล้ว logout 1 บัญชี
- **DB**:
  - `mq "db.sessions.countDocuments()"` = จำนวน session ที่ยัง login
  - เอกสารไม่มี `eyJ` (JWT) และไม่มีรหัสผ่าน
  - TTL index มีอยู่
  - หลัง logout เหลือน้อยลง 1

#### U15.5 restart web — ยังใช้งานต่อได้ · จอ

- **ทำ**: ระหว่างขาย (มีบิลพักและหน้าจอล็อกอยู่) สั่ง `$C restart web` แล้ว reload
- **จอ**: ยัง login อยู่ บิลพัก / สถานะล็อกยังอยู่ (เก็บที่ server) ไม่มี error

#### U15.6 MongoDB หยุด → กลับมา · จอ

- **ทำ**: `$C stop mongo` → reload หน้า / ลอง login → `$C start mongo` → ลองใหม่ (ไม่ restart web)
- **จอ** (ผลที่ต้องการ):
  - ตอน mongo หยุด: แอปแจ้ง error เป็นข้อความ ไม่ค้าง ไม่เปิดเผยรายละเอียดภายใน
  - mongo กลับมา: ใช้ต่อได้โดยไม่ต้อง restart web
- **บันทึกตามจริง**: ถ้า web ล่ม / ต้อง restart ให้เป็นสิ่งที่เจอ

#### U15.7 api ตัวหนึ่งหยุด · จอ

- **ทำ**: `$C stop api1` ระหว่างไล่เปิด 5 เมนูและขาย 1 บิลที่ NOVAT → `$C start api1`; ต่อด้วย `$C restart api2` ระหว่างใช้งาน
- **จอ**: ไม่มี error / 5xx ที่ผู้ใช้เห็น (lb ส่งไปตัวที่เหลือ); บิลได้เลขต่อเนื่อง
- **DB**: เลขบิลไม่ข้าม / ไม่ซ้ำ; log ของ lb ไม่มี 502 ค้าง (ยอมรับ retry ที่สำเร็จ)

#### U15.8 จำกัด login ที่ web นับเฉพาะที่ไม่ผ่าน · API

- **ทำ**: ผ่าน web (cookie + XSRF) login jum ถูก 25 ครั้งติด แล้วผิด 1 ครั้ง
- **ผลที่คาด**: 25 ครั้งได้ 200; header `RateLimit` remaining ไม่ลดตอนสำเร็จ แต่ลด 1 ตอนผิด (C3-7)
