บรรทัดละ 1 ข้อ — รายละเอียด / เหตุผลอยู่ในไฟล์ที่ชี้ไป · กฎที่เป็นผลของข้อตัดสินใจสรุปไว้ใน `CLAUDE.md`

## SKU / คลัง / โปร / ชำระเงิน (2026-10-04, ใน `CLAUDE.md` หัวข้อ Data flow)

- ต้นทุน: serial = ทุนเฉพาะเครื่อง, non-serial = ทุนเฉลี่ยเคลื่อนที่ (`costing.model.ts`)
- SKU บริการ (`itemType: service`) ไม่มีสต็อก, `cost` = COGS ต่อการขาย
- โปรโมชั่น 3 แบบ, ซ้อนกันได้ตาม `priority` / `stackable`; เริ่มแล้วแก้ได้บางช่อง ลบไม่ได้
- ช่องทางชำระเงิน: แบ่งจ่ายหลายช่องทาง, เฉพาะเงินสดทอนได้และปัดเศษ; ต้องมีเงินสดที่ใช้งาน ≥ 1
- ราคาขายอยู่ใน `SkuPrice` ตามช่วงวันที่เท่านั้น
- ใบลดหนี้ (คืนข้ามวัน, admin), ใบเปลี่ยนสินค้า (SKU เดิม ไม่มีเงิน), ใบกำกับเต็มรูป (ลงวันที่วันขาย), รายงานภาษีขาย
- รายละเอียด POS: [`pos-plan.md`](pos-plan.md) หัวข้อ 9–12
