- ต้นฉบับ: `manual.html` (HTML + CSS พิมพ์ A4 ไฟล์เดียว) · ภาพ: `img/<บท>-<ลำดับ>-<ชื่อ>.png|jpg`
- สร้าง PDF: `./build-pdf.sh` → `an22-user-manual.pdf` (Chrome headless, ต้องมีฟอนต์ Noto Sans Thai)
- ภาพถ่ายจาก stack local (`an22-api/scripts/local-stack.sh`, http://localhost:14000) วันที่ 7–8 พ.ย. 2569 ด้วย Claude in Chrome
- แก้ UI แล้วควรถ่ายภาพที่เกี่ยวข้องใหม่ (ชื่อไฟล์เดิม) แล้ว build ใหม่

- สาขา HQ (00000) · BN (00001) · เครื่อง POS 1 (HQ) · 2 (BN) · แพ็กเกจ Pro (ทดลองใช้)
- SKU: 3 รายการสร้างด้วยฟอร์ม/หน้าจอ, ที่เหลือจาก `data/sku-demo.xlsx` (`node docs/user-manual/data/mk-sku-demo.cjs`)
- รับเข้าจาก Excel: `data/receive-demo.xlsx` (`mk-receive-demo.cjs`, แถว OLD-MS ผิดโดยตั้งใจ)
- หมวดหมู่ ผู้จำหน่าย 1 ราย ช่องทางชำระ ราคา โปร 3 รายการ และสต็อกเริ่มต้นบางส่วน สร้างผ่าน API ของแอป (fetch จากหน้าเว็บที่ login แล้ว) — ไม่ได้เขียน DB ตรง
- ขายกะแรกก่อนเที่ยงคืน 7 พ.ย. แล้วทำใบลดหนี้ / ยกเลิกบิล / เปลี่ยนสินค้าหลังเที่ยงคืน (ใบลดหนี้ต้องเป็นบิลวันก่อน) · กะ `SH-HQ-20261108-01` ยังเปิดอยู่
- `data/snap.sh <ชื่อ> [ลำดับ]` คัดลอกภาพหน้าจอล่าสุดของ Claude in Chrome เข้า `img/`
