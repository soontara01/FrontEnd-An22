### ข้อสังเกต

- **1.7:** กรณีทศนิยมเกิน 2 ตำแหน่ง (`100.555`) ระบบบล็อกถูกต้อง แต่ข้อความยังขึ้นว่า "เงินทอนตั้งต้นต้องเป็นจำนวนเงินที่ไม่ติดลบ" ซึ่งไม่ตรงกับสาเหตุ
  ควรแยกข้อความใน `openShiftError()` เช่น "เงินทอนตั้งต้นมีทศนิยมได้ไม่เกิน 2 ตำแหน่ง"
- ระหว่างทดสอบ 1.11 ครั้งแรก ค่าที่พิมพ์ในช่องเงินทอน (`type="number"`) ไม่เข้า (ยังเป็น 0) และกดเปิดกะแล้วไม่มีกะถูกสร้าง
  ลองใหม่ด้วย Ctrl+A แล้วพิมพ์ก็ใช้ได้ — น่าจะเป็นเรื่องของเครื่องมืออัตโนมัติกับ number input มากกว่าบั๊กของแอป แต่ยังไม่ยืนยัน
