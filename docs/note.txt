ด้ครับ วันหลังใช้ได้ทั้งเครื่องนี้และเครื่องอื่น

สำคัญ: ไฟล์แผนยังไม่ได้ commit

docs/test-before-saas.md กับ docs/test-plan.md ยังอยู่แค่บนเครื่องนี้ ถ้าจะไปทำเครื่องอื่น ต้อง commit แล้ว push ขึ้น branch feature/step3 ก่อน ไม่งั้นอีกเครื่องจะไม่เห็นไฟล์ จะให้ผม commit + push ให้ไหมครับ

เตรียมเครื่องที่จะใช้ทดสอบ (ทำครั้งเดียว)

git pull แล้ว nvm use (Node 24) แล้ว npm install
ติดตั้ง Claude in Chrome จาก https://claude.ai/chrome แล้ว login claude.ai ใน Chrome ด้วยบัญชีเดียวกับ Claude Code
เปิด Claude Code ในโฟลเดอร์โปรเจกต์
ใช้ Chrome บนเครื่องเดียวกับที่รันโปรเจกต์จะง่ายสุด ถ้าเป็นคนละเครื่อง ต้อง forward port 4200 ไปที่เครื่องที่เปิด Chrome
คำสั่งที่ใช้ (copy ไปวางได้เลย)

รอบแรก:


ทดสอบหน้าจอตาม docs/test-before-saas.md รอบ R1 (หัวข้อ 1–3)
ทำตาม "เตรียมก่อนเริ่ม" ก่อน (รัน npm start ถ้ายังไม่รัน, ล้าง mock db)
ใช้ Claude in Chrome ให้ฉันดูหน้าจอไปด้วย
กรอกผลในคอลัมน์ "ผล" ทุกข้อ เจอบั๊กให้เพิ่มในตาราง "บั๊ก / ข้อสังเกตที่พบ"
ยังไม่ต้องแก้โค้ด
รอบต่อ ๆ ไป:


ทดสอบต่อ docs/test-before-saas.md รอบ R2 (ไม่ต้องล้าง mock db)
เปลี่ยน R2 เป็นรอบที่ต้องการ (R2 ถึง R7) แต่ห้ามล้าง mock db ระหว่างรอบ เพราะแต่ละรอบใช้ข้อมูลจากรอบก่อน ถ้าเปลี่ยนเครื่องกลางทาง ข้อมูลจากรอบก่อนจะไม่ตามไปด้วย ต้องเริ่มใหม่จาก R1

ระหว่างทดสอบ

ถ้ากล่องขออนุญาตของ Chrome เด้งขึ้นมา ให้เลือก "Yes, allow localhost:4200 for this session" ครั้งเดียว แล้วจะไม่ถามอีกจนจบ session
อย่าคลิกในแท็บที่ Claude กำลังใช้ จะชนกับคำสั่งของ Claude
ถ้าหน้าต่างพิมพ์ของเบราว์เซอร์เด้งขึ้นมา ให้กดยกเลิกเอง
รอบหนึ่งใช้เวลานาน ถ้ายังทำไม่จบรอบ สั่งต่อได้ด้วย ทดสอบต่อจากข้อ X.Y ผลที่กรอกไปแล้วอยู่ในไฟล์ ไม่หาย
หลังทดสอบแต่ละวัน

ผลที่กรอกจะอยู่ใน docs/test-before-saas.md ให้ commit + push ทุกครั้งก่อนเปลี่ยนเครื่อง ไม่งั้นผลจะค้างอยู่บนเครื่องเดิม
